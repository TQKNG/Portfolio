# Portfolio assets

Store optimized, web-ready assets under a folder named for their content.

Use `projects/<project-slug>/` for project imagery and `blog/<post-slug>/` for blog imagery.

Use `cover.webp` for cards and hero imagery, followed by numbered files for gallery or article images.

Use `preview.mp4` for an optional, muted project-card hover preview.

Set `localPreviewVideo` to the local asset and `previewVideo` to an optional hosted fallback URL.

Keep filenames lowercase and kebab-case.
